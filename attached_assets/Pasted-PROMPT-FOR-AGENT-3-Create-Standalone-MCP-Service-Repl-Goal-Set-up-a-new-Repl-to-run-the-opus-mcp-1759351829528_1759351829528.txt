Context:

I'm creating a separate Repl for the MCP (Model Context Protocol) service
The main app currently has the opus-mcp code in the /opus-mcp directory
The new Repl will run independently on port 4000
The main app (port 5000) will make HTTP calls to this MCP service
Files to Create:

package.json - Copy from /opus-mcp/package.json
tsconfig.json - Copy from /opus-mcp/tsconfig.json
src/ directory structure:
src/server.ts (from opus-mcp/src/server.ts)
src/config.ts (from opus-mcp/src/config.ts)
src/auth.ts (from opus-mcp/src/auth.ts)
src/errors.ts (from opus-mcp/src/errors.ts)
src/contracts/index.ts (from opus-mcp/src/contracts/index.ts)
src/tools/*.ts (all tool files from opus-mcp/src/tools/)
src/agent/prepAgent.ts (from opus-mcp/src/agent/prepAgent.ts)
src/orchestrator/*.ts (both files from opus-mcp/src/orchestrator/)

Copy the required storage and client modules to this Repl, OR
